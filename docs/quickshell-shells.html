The shortlist

These are shell products with releases, packaging, documentation, and active contributors. Personal dotfile collections are excluded because adopting one would make you its maintainer.

recommended Quickshell Hyprland NixOS 26.05 Catppuccin Mocha

DankMaterialShell

DMS is the best balanced replacement for Ultrashell. It is a full shell with a bar, launcher, notifications, clipboard, lock screen, quick settings, monitor controls, system monitoring, and a plugin system. The current project supports both Hyprland configuration formats.

Why it fits development work

The launcher, clipboard history, focused-workspace controls, Do Not Disturb, and system monitors reduce context switching. The shell does not need to own your terminal, editor, language tools, or per-project nix develop environments.

Nix integration

NixOS 26.05 has programs.dms-shell, including a systemd user service and a configurable quickshell.package. This matches the repository's stable Hyprland and Quickshell ownership policy.

Catppuccin

catppuccin/dankmaterialshell provides Mocha, Macchiato, Frappé, Latte, and accent choices through one custom theme file.

Maintenance signal

The project had about 8,100 GitHub stars, more than 100 listed contributors, and a release on 17 September 2026 when this report was checked.

Boundary to enforce

Disable dynamic application theming at first. Keep Ghostty, Neovim, tmux, GTK, and Qt under the existing Nix modules. Let DMS own only its shell UI until each extra template has a clear owner.

runner-up Quickshell Hyprland-first Catppuccin Mocha built in own Quickshell input

Caelestia Shell

Caelestia is the strongest choice if visual craft and direct Hyprland integration matter more than package simplicity. It has a launcher, command actions, Vim-style launcher keys, notifications, performance views, a lock screen, and a mature CLI.

Choose it for a Hyprland-only workstation

Caelestia directly uses Quickshell's Hyprland services and global shortcuts. Its CLI includes Catppuccin Mocha as a stock scheme, plus Frappé, Macchiato, Latte, Gruvbox, Nord, Rosé Pine, and dynamic wallpaper colors.

Developer controls

The launcher can run applications, calculations, shell actions, wallpaper changes, and theme changes. Its configuration exposes Vim keybindings and keeps dangerous session actions disabled by default.

Nix integration

The project ships a Home Manager module and systemd user service. It also packages a CLI. Nixpkgs unstable has both caelestia-shell and caelestia-cli.

Maintenance signal

The shell had about 12,400 GitHub stars, 88 listed contributors, and a release on 18 September 2026 when this report was checked.

Repository mismatch

NixOS 26.05 does not package Caelestia. Its flake pins a separate upstream Quickshell revision, while this repository deliberately couples Quickshell to stable Hyprland. That is a real maintenance cost, not an install detail.

conditional option Hyprland NixOS Catppuccin not Quickshell in v5

Noctalia is the exception

Noctalia v5.1 is worth considering only if Quickshell becomes optional. The current shell is a native Wayland and OpenGL ES application. It has no Qt or GTK dependency. NixOS 26.05 still packages the older Quickshell-based v4.7.6, but that is not the project's current architecture.

Best ownership model, wrong framework

Noctalia v5 explicitly avoids taking over compositor settings and dotfiles. It has TOML configuration, a built-in Catppuccin palette, templates, plugins, and a broad set of shell functions. It may be the better long-term shell if the framework requirement was only a proxy for quality and maintainability.

Workstation comparison

"Developer-friendly" means predictable keyboard use, clear config ownership, reliable multi-monitor behavior, and no hidden writes to editor or terminal files.

A low-risk trial

Trial the shell as one bounded component. Do not adopt its full dotfiles, greeter, idle stack, or application templates at the same time.

  1. Install DMS from the release channel.

    Use the NixOS 26.05 module and its pkgs.quickshell. Do not add a second Quickshell flake while the compositor remains version-coupled.

  2. Run it beside the existing config for one session.

    Stop Ultrashell, start DMS, and leave Hyprland bindings, hyprlock, hypridle, hyprpaper, notifications, and application themes unchanged for the first pass.

  3. Apply only Catppuccin Mocha.

    Load the official DMS Catppuccin JSON. Keep dynamic app theming disabled so the shell cannot rewrite editor, terminal, GTK, or Qt configuration.

  4. Test the real workday.

    Check multi-monitor resume, workspace switching, full-screen apps, screen sharing, notification focus, clipboard use, terminal spawning, and a long development session. Remove Ultrashell only after that path is stable.
